# Server Health & Network Diagnostic Tool

A Bash script to check server health (disk, memory, processes) and
network connectivity (DNS, reachability, open ports) on a Linux server.

## Usage
./healthcheck.sh

## Checks performed
- Disk usage
- Memory usage
- Top CPU-consuming processes
- DNS resolution test
- Internet connectivity test
- Listening ports
